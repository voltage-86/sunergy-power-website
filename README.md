# Sunergy Power

A modern multi page website for **Sunergy Power**, a fictional residential solar energy company, created for a school assessment project.

## Overview

Sunergy Power is a responsive website designed to promote residential solar solutions, including solar panel sales, professional installation, and ongoing system maintenance.

The website provides information about how solar energy works, its environmental benefits, and the services offered by Sunergy Power. The design focuses on a clean, modern interface with accessibility and responsive layouts for different screen sizes.

## Pages

- Home (index.html)
- How It Works (howitworks.html)
- Green Energy (greenenergy.html)

## Features

- Fully responsive multi page layout
- Responsive navigation bar with mobile hamburger menu
- Hero sections with large background imagery
- Home page image slideshow with navigation controls
- Informational sections explaining solar energy
- Step by step "How It Works" section
- Environmental benefits and statistics
- Responsive service and information cards
- Image attribution dropdown in the footer
- Consistent navigation and footer across all pages
- Accessibility considerations including:
  - Readable colour contrast
  - Descriptive image alt text
  - Clear headings and page structure
  - Keyboard friendly navigation
- Favicon using the Sunergy Power logo

## Design

The website uses a clean green and off white colour scheme to match the renewable energy theme.

- Dark green for navigation, buttons, and branding
- Gold for Sunergy Power branding and section headings
- Off white backgrounds for readability
- Green outlined cards and interface elements
- Open Sans for readable body text

The layout was designed to work across desktop, tablet, and mobile screen sizes.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Bootstrap Icons
- Google Fonts (Open Sans)
